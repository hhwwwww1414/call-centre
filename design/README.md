# Исходники графики

`v2w_square_avatar_1024.png` — фирменный знак VIN2WIN от заказчика:
квадрат 1024×1024, зелёный градиентный логотип «v2w» на прозрачном фоне.
Сам знак занимает узкую горизонтальную полосу, вокруг много пустого места.

Из него собраны рабочие файлы. Пустые поля обрезаются: без этого в шапке
сайдбара знак ужимался бы до нечитаемого размера.

| Файл | Что это |
|---|---|
| `public/logo.png` | Знак без полей, 640px по ширине. Используется в интерфейсе через `components/brand/logo.tsx` |
| `app/icon.png` | Иконка вкладки браузера, 512×512, знак по центру с полем |
| `app/apple-icon.png` | Иконка для ярлыка на iOS, 180×180, на белом фоне (прозрачный iOS заливает чёрным) |

## Пересобрать

Если заказчик пришлёт обновлённый знак — положить его сюда под тем же
именем и выполнить:

```bash
node scripts/build-brand-assets.mjs
```

Скрипт использует `sharp`, который уже стоит транзитивно вместе с Next.
